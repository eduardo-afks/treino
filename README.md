# DUDU FITNESS — versão sem login

## Como publicar
1. Extraia este ZIP.
2. Envie os arquivos de dentro da pasta `dudu_fitness` para o repositório do GitHub Pages.
3. Aguarde a publicação e abra o site.

O aplicativo abre diretamente na página inicial, sem tela de login ou dependência do Supabase.

## Dados e privacidade
- Rascunhos, histórico e progresso ficam salvos no armazenamento local do navegador.
- Os dados não sincronizam com outros computadores ou celulares.
- Limpar os dados do navegador pode apagar os registros. Use “Exportar dados” na tela Evolução para guardar uma cópia.
- O histórico que existia apenas no Supabase não é importado automaticamente nesta versão.
- Os GIFs são carregados de sites externos e precisam de conexão com a internet; alguns links podem ficar indisponíveis.
